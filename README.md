# YouTube Downloader Pro (PHP)

A modern PHP website to download YouTube video/audio using `yt-dlp`, with a beautiful UI powered by Bootstrap and the AOS animation plugin.

## Requirements

- PHP 8+
- `yt-dlp` available in server PATH
- Optional: `ffmpeg` for best format merging/audio conversion

## Run locally

```bash
php -S 0.0.0.0:8080
```

Then open:

- `http://localhost:8080`

## Notes

- This project supports only YouTube links.
- Download content only when you have legal rights/permission.
